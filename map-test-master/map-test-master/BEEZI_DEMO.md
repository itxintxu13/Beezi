# 🌍🐝 Beezi - Sistema Satelital para Protección de Polinizadores

## 🎯 Presentación para Hackathon

### ¿Qué es Beezi?

Beezi es una plataforma revolucionaria que utiliza **datos satelitales** y **inteligencia artificial** para proteger a los polinizadores mediante:

- 🛰️ **Detección en tiempo real** de floración de plantas usando imágenes MODIS, Sentinel y ASTER
- 📊 **Predicción de escasez** de recursos florales que afectan a las abejas
- 🗺️ **Mapeo de rutas críticas** de polinización 
- 🌱 **Recomendaciones automáticas** para restauración ecológica

### 🚀 Demo Funcional - Características Destacadas

#### 💫 Experiencia Visual Impactante
- **Mapa 3D** con perspectiva satelital de España
- **Animaciones en tiempo real** del "pulso de vida" de las plantas
- **Rutas animadas** de polinizadores con marcadores de abejas 🐝
- **Mapa de calor** mostrando concentración de actividad
- **Efectos visuales** con niebla atmosférica y iluminación dinámica

#### 🎮 Controles Interactivos
- **Slider temporal** para navegar por los meses del año
- **Vista timelapse** mostrando ciclos anuales de floración
- **Panel de estadísticas** en tiempo real
- **Protocolo de emergencia** para situaciones críticas
- **Popups informativos** con datos detallados de cada zona

#### 📈 Datos Realistas
- **12 hotspots** distribuidos por toda España
- **Especies florales específicas** de cada región
- **Conteos de polinizadores** y métricas ambientales
- **Períodos de floración** estacionales
- **Indicadores de riesgo** por zona

### 🎨 Características Técnicas

#### Stack Tecnológico
- **Angular 20** con TypeScript
- **Mapbox GL JS** para mapeo 3D avanzado
- **SCSS** con animaciones CSS3
- **GeoJSON** para datos geoespaciales
- **Responsive Design** para todos los dispositivos

#### Funcionalidades Avanzadas
- **Animaciones fluidas** con requestAnimationFrame
- **Efectos de partículas** para simular movimiento de abejas
- **Gradientes dinámicos** basados en intensidad de floración
- **Interactividad** completa con eventos de mouse/touch
- **Carga progresiva** con splash screen temático
